# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

- Run: `SPRING_PROFILES_ACTIVE=demo ./mvnw spring-boot:run` (in-memory H2) or `docker compose up -d db && ./mvnw spring-boot:run` (PostgreSQL); app at http://localhost:8080.
- Test: `./mvnw test` (Java, single class: `-Dtest=ClassName`) and `npm test` (Jest, single file: `npx jest <path>`). Report both counts before saying done.
- Backend: Spring Boot 3.2 / Java 17 in `src/main/java/com/marlowefinch/ops/`; plain SQL via Spring JDBC in `*Repository`, thin `*Controller`s, records as responses. No JPA.
- Schema and seed: Flyway in `src/main/resources/db/migration/`; `V2__seed.sql` is generated by `tools/make_seed.py`, never hand-edited.
- Tests run on the `demo` profile (H2 in PostgreSQL mode), so SQL must work on both H2 and PostgreSQL.
- "Today" is pinned to 2026-09-21 (`ops.today`, `ClockConfig`); always use the injected `Clock`.
- Frontend: plain JS/HTML/CSS in `src/main/resources/static/`, no framework or build step; charts are inline SVG; `app.js` exposes `initApp(document, fetchImpl)` for Jest.
- Every new element id in `index.html` must be added to `REGISTERED_IDS` in `src/test/javascript/setup/loadApp.js`, or `harness.test.js` fails.
- Workshop material lives in `workshop/` and `docs/`; tickets are in `docs/tickets/`.
- pom.xml dependencies are frozen. Any change needs a CHG ticket.
