# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this is

`ops-dashboard`: a Spring Boot 3.2 / Java 17 read-only JSON API (`/api/*`) over PostgreSQL, plus a framework-free JavaScript page in `src/main/resources/static/`. The repo is also a Claude Code workshop: `workshop/` holds the labs, `docs/tickets/` the tickets (TODO-231/232/233), `docs/examples/` reference hooks, agents and skills.

## Commands

```bash
./mvnw test                                   # Java tests (JUnit 5, H2, MockMvc); no DB needed
./mvnw test -Dtest=DashboardControllerTest    # single test class (append #method for one method)
npm install && npm test                       # Frontend tests (Jest + jsdom)
npx jest src/test/javascript/render.test.js   # single Jest file (-t "name" for one test)
SPRING_PROFILES_ACTIVE=demo ./mvnw spring-boot:run   # run on in-memory H2, no Docker
docker compose up -d db && ./mvnw spring-boot:run    # run on PostgreSQL 16 (default profile)
```

App at http://localhost:8080.

## Architecture

- **Backend**: Spring JDBC with plain SQL, no JPA. `DashboardRepository` / `VendorRepository` hold the queries; thin `*Controller` classes map them to endpoints; responses are Java records. Schema and seed come from Flyway (`db/migration/V1__schema.sql`, `V2__seed.sql`).
- **Profiles**: `postgres` is the default; `demo` is H2 in PostgreSQL mode with the same migrations. Tests always use `demo`, so SQL must work on both.
- **Pinned clock**: "today" is fixed at 2026-09-21 (`ops.today`, `ClockConfig`). Always use the injected `Clock`, never `LocalDate.now()` without it. Date ranges default to the last 30 days ending today (`DateRange.resolve`); there is intentionally no input validation yet (TODO-232).
- **Seed data**: generated by `tools/make_seed.py` (also writes `docs/data/deliveries-last-30-days.csv` and a git-ignored answer key). Regenerate rather than hand-editing `V2__seed.sql`.
- **Frontend**: `app.js` wraps everything in `initApp(document, fetchImpl)` and exports via `module.exports`, so the same code runs in the browser and in Jest. Charts are inline SVG; no build step, no framework.
- **Frontend test harness**: `src/test/javascript/setup/loadApp.js` loads `index.html`, fakes every `/api` endpoint with `FIXTURES`, and lists `REGISTERED_IDS`. `harness.test.js` fails if `index.html` contains an element id not in that list, so register every new id there.

## Rules

- `pom.xml` dependencies are frozen. Any change needs a CHG ticket.
- Before declaring done: run both `./mvnw test` and `npm test` and report both counts.
